# SCSU実運用プレイブック — 自分で回して実績を作る

目的: SCSUのThreadsアカウントを本番運用し、**「◯週間無停止・投稿◯本・エンゲージ率◯%」という数字**と
**月次レポートPDF**を営業資産にする。商談で見せるのはコードではなくこの実績。

## Week 0: セットアップ（1回・2〜3時間）

やることは4つのアカウント/キーの準備とデプロイ。全てREADMEに詳細手順あり。

- [ ] **Railway**: プロジェクト作成 → リポジトリ接続（Root Directory: `apps/threads-studio`）→ MySQLプラグイン追加
- [ ] **Google OAuth**: クライアントID作成、リダイレクトURI登録 → `GOOGLE_CLIENT_ID/SECRET`
- [ ] **Meta for Developers**: Threads APIアプリ作成 → 長期トークン取得
  - 自分のアカウントだけならアプリは**開発モードのままでよい**（自分がアプリ管理者なので審査不要）
  - トークンは設定画面から登録。以後の60日更新はアプリが自動でやる
- [ ] **Anthropic APIキー**: `ANTHROPIC_API_KEY`（AIアシスト用）
- [ ] デプロイ後: 自分のGoogleアカウントでログイン（最初の1人=管理者）→ 設定画面でアカウント登録 → タイムゾーンと投稿時刻（朝8:00 / 夕18:00 など）を設定
- [ ] **運用開始日をメモする**（「◯週間無停止」の起点）

## 毎週の運用（週30分・これだけ）

週1回、決まった曜日に:

1. AIアシストで来週分の下書きを生成（テーマを3つ入れて5案×3回）
2. 良いものを選んで手直し → カレンダーで来週の日付に配置（1日2本 × 7日 = 14本）
3. 承認フローONなら一括承認

あとは自動投稿に任せる。**毎日やることはゼロ**（通知メールが来た時だけ対応）。

## 営業で使える状態の判定

以下が揃ったら営業開始（プレイブック本編のDM/ピッチへ）:

- **4週間無停止**（最低ライン。8週あれば強い）
- 月次レポートPDF 1〜2枚
- ビフォーアフターの数字1つ（例: 「手動運用時は週2投稿 → 自動化後は週14投稿、作業時間は週30分」）

ピッチでの使い方: 「実際に私自身のアカウントで◯週間、毎日朝夕の自動投稿を無停止で回しています。
これがその月次レポートです」→ そのままデモへ。

## トラブル時

- 投稿エラー・トークン失効は**メール通知**が来る（`RESEND_API_KEY`/`NOTIFY_EMAIL` 設定時）。設定推奨
- サーバーが止まっていた間のスロットは復帰後に遅れて投稿される（投稿されないことはない）
- 「無停止」が途切れたら起点をリセットして再カウント。原因と対処をこのファイルに追記しておくと、
  商談で「障害時はこう対応する」と語れる材料になる
