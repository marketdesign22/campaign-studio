# Threads Studio 販売プレイブック

対象プロダクト: **Threads Studio**（旧 SCSU Threads Auto Poster）。
Threads運用ダッシュボード。複数アカウント・承認フロー・AI原稿アシスト（日英）・
月次レポート（PDF）・ホワイトレーベル・トークン自動更新・日英切替UI・
タイムゾーン PT/MT/CT/ET/JST 対応。ソースは本リポジトリ `apps/threads-studio/`。

## 売り方の原則

1. **ツールではなくDone-for-you（運用代行）を売る。** ツール単体はBuffer等（$15-100/mo）と価格競争になる。「あなたは承認ボタンを押すだけ」という結果を売る。
2. **武器は3つ**: AIアシスト（商談で相手のトーンの下書きを実演生成→一番驚かれる）、承認フロー（勝手に投稿されない安心）、月次レポート（継続課金の理由）。
3. デモは常設URL＋`pnpm seed:demo` のダミーデータ。コードは見せない。
4. まず自分のアカウントで実運用し「◯週間無停止」の実績を作ってから売る。

## 日本市場

| プラン | 内容 | 月額 |
|---|---|---|
| ライト | ツール＋初期設定（原稿は客側） | 2〜3万円 |
| スタンダード（主力） | ＋原稿作成 月40-60本＋月次レポート | 5〜8万円 |
| プレミアム | ＋企画・定例 | 10〜15万円 |

- 初期費用 3〜5万円（値引きカードとして定価設定必須）
- モニター: スタンダード相当を月3万円×3ヶ月、事例掲載条件。期限後の正価復帰を文書で約束
- 月1万円以下は受けない（サポート1回で赤字）
- ターゲット: 学校・塾・習い事・地域の小規模事業者。販路ゼロならココナラ/クラウドワークスで実績作り

## 米国市場

| プラン | 月額 |
|---|---|
| Light | $200〜300 |
| Standard（主力） | $750〜1,200 |
| Premium | $2,000〜3,000 |

- セットアップ $500〜1,000 / モニター $400〜500×3ヶ月
- 安すぎる価格（$100等）は逆に信用を落とす。時給換算$75〜150から逆算
- **ニッチ = 米国内の日系ビジネス**（LA/OC/NY/シアトルの日本食レストラン・美容室・日系企業支社・日本語学校）。「日英両方で毎日発信」はBufferが解決しない痛み
- チャネル: Googleマップ/Yelpで SNSが3週間以上止まっている日系店舗をリスト化（週50件）→DM/訪問。びびなび・Lighthouse・羅府新報。日系商工会議所(JCCI)。紹介（「同業紹介で1ヶ月無料」を必ず言う）
- ピッチ3文: ①お店のSNS止まっていませんか（具体的に指摘） ②日英で作成し毎日自動配信、あなたは週1回承認ボタンだけ ③月次レポート付き、まず2週間無料
- フロー: DM → 15分デモ（AI下書きをその場で生成）→ 2週間無料トライアル → ミニレポート提示 → 契約
- 目安: 週50接触→返信5-10%→商談3-5→成約1。1社の稼働は月4-6時間、10社までワンオペ可

## 買い切り要望への対応

導入一式 20〜40万円（$3,000〜6,000）＋保守 月1〜2万円（$150〜300）。
**保守なし納品は受けない**（Meta仕様変更で必ず壊れる）。

## 契約の必須条項

責任上限=月額3ヶ月分 / Meta API仕様変更の免責 / トークン預かりの同意 / 30日前解約通知。
米国クライアントへは日本事業者のまま請求可（Stripe/Wise、求められたらW-8BEN）。

## 技術上の販売ブロッカー（受注前に確認）

- クライアントのThreadsアカウント接続には、自分のMetaアプリに客をテスター招待（〜数社）か、Metaアプリ審査(Advanced Access)通過（SaaS展開時）が必要
- ホスティング費（Manus）とAI API費は月額に織り込む（原価は月数千円、粗利9割前後）
