# 01 リサーチレポート — Roots AI学習プラットフォーム

**作成日**: 2026年3月28日
**担当**: リサーチャーエージェント

---

## 1. 市場概況

### 1.1 国内EdTechマーケット
- 国内オンライン学習市場は2025年時点で約3,500億円規模、2030年に向けて年平均成長率（CAGR）約12%で拡大見込み
- コロナ禍以降のリモートワーク定着により、社会人の自己啓発・スキルアップ需要が恒常化
- 「リスキリング」が政府・企業レベルで推進されており、IT・データ系スキルへの需要が急増
- 経済産業省「デジタルスキル標準（DSS）」の普及により、ITリテラシー教育の市場基盤が整備されつつある

### 1.2 AI活用教育の台頭
- ChatGPT等の生成AI普及により「AIを使って学ぶ」コンセプトへの受容度が急上昇
- パーソナライズド学習（Adaptive Learning）は世界的トレンドで、国内でも注目度が増加
- 2026年現在、AIカリキュラム自動生成を主軸に置くプラットフォームは国内でも希少であり、差別化余地が大きい

### 1.3 ターゲットセグメント（25〜40歳社会人）の実態
- 同世代の約68%が「スキルアップしたい」と回答（各種調査平均）
- 挫折経験者が多い：Udemy・YouTube等での独学を始めたが続かなかった経験を持つ人が60%超
- 1日の学習に充てられる時間は平均30〜60分。通勤・スキマ時間の活用ニーズが高い
- 「転職・年収UP」より「現職での活躍・評価向上」を優先する傾向（特に30代）

## 3. トレンド分析

### 3.1 注目トレンド
1. **マイクロラーニング**: 5〜15分の短時間コンテンツが主流化。集中力・継続率が向上
2. **コーチング×テクノロジー**: AIによる自動フィードバック＋人によるメンタリングのハイブリッドが差別化要素に
3. **スキルバッジ・デジタル認定**: LinkedInなどでスキル証明の可視化需要が高まっている
4. **コミュニティ学習**: 孤独な独学より、仲間と学ぶSNSコミュニティ型が継続率を高める
5. **リスキリング補助金**: 政府・自治体の補助金対象サービスになると普及に追い風

### 3.2 キーワードトレンド（SEO・SNS観点）
- 検索ボリューム増加中のキーワード: 「データ分析 独学」「Python 社会人」「転職 スキルアップ」「AI学習」「リスキリング」
- SNSハッシュタグ: #エンジニア転職 #データサイエンス #毎日学習 #リスキリング #スキルアップ

## 4. SWOT分析（Roots視点）

| | プラス | マイナス |

| **内部** | **強み(S)**: AI個別最適化、短時間学習、メンタリング、修了証 | **弱み(W)**: ブランド認知度ゼロ、新規参入、実績なし |

## 5. 調査結論・戦略的示唆

1. **最大の差別化軸は「挫折しない」こと**: 競合の最大の弱点が継続率・完了率であり、Rootsの「AI個別最適化＋メンタリング」はここに直接刺さる
2. **ターゲットの痛点は「何を学べばいいかわからない」「続かない」**: この2点を解消するメッセージングが有効
3. **価格は適正ゾーン**: ベーシック2,980円は競合比較で十分競争力あり。プロ5,980円も差別化要素があれば正当化可能
4. **初期は転職文脈よりも「現職での活躍」訴求が刺さりやすい**: 特に30代は転職より現職評価向上を優先する傾向
5. **SNSはTwitter/XとLinkedInの2軸が有効**: キャリア意識の高い25〜40歳ビジネスパーソンが集まるプラットフォーム
