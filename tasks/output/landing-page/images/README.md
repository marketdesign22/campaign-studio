# 写真の置き場所

このフォルダに、送っていただいた5枚の写真を以下のファイル名で保存してください。
保存すると、ランディングページのヒーローとスライドショーに自動で表示されます。
（写真がまだ無い状態でも、ページは崩れずにプレースホルダー表示になります）

| ファイル名 | 使う写真 | 表示される場所 |
|-----------|----------|----------------|
| `01.jpg` | 校内（緑の壁の前でみんなでポーズ）の写真 | ヒーロー／スライドショー「アットホームで、みんな仲良し」 |
| `02.jpg` | 屋外でHEIバナーを持った集合写真 | ヒーロー／スライドショー「校外学習で、LAの街へ」 |
| `03.jpg` | California Science Center（飛行機の下）での集合写真 | スライドショー「California Science Center を見学」 |
| `04.jpg` | The Broad 美術館前の集合写真 | ヒーロー／スライドショー「現代アートの殿堂 The Broad へ」 |
| `05.jpg` | 教室での授業風景（PERSONAL STATEMENT のホワイトボード） | スライドショー「少人数クラスの授業風景」 |

## 注意
- ファイル名は半角の `01.jpg` 〜 `05.jpg` にしてください（拡張子も小文字 `.jpg`）。
- PNGで保存したい場合は、index.html 内の `images/0X.jpg` を `images/0X.png` に書き換えてください。
- 横長（16:9前後）の写真がきれいに表示されます。縦長写真は中央が切り取られて表示されます。
